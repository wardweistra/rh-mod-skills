# Data model: annotate review (008)

Annotate plan and bindings schemas are unchanged ([005](../005-rh-mod-annotate/data-model.md)).

## Review HTML

**Path**: `models/<id>/process/plans/annotate-review.html`

Generated bytes only. Not L2. Regenerated on each export.

## Picks file

**Typical download name**: `annotate-picks.yaml` (any path passed to `--from`)

```yaml
model: nkr-breast
picks:
  - path: patientgegevens.gesl
    decision: accept          # accept | reject | replace | unbound | pending
    pick: 1                   # 1-based rank; required for accept; null otherwise
    reason: ""
    chosen:                   # required for replace; ignored for accept (copied from candidate)
      system: null
      code: null
      display: null
```

`reject` and `pending` are skip (no bindings row). `pick` must match a candidate rank on that plan element for `accept`.

## Plan fields import writes

| Picks | Plan element |
|-------|----------------|
| accept + pick N | `decision: accept`, `chosen` = candidate N |
| unbound + reason | `decision: unbound`, `reason` set, `chosen` cleared |
| replace + chosen | `decision: replace`, `chosen` from picks |
| reject / pending | `decision` accordingly; `chosen` unchanged or cleared |

`status` on the plan file → `draft`.
