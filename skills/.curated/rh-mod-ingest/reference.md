# rh-mod-ingest reference

CLI owns all durable writes. This file is the field list the agent may reason about.

## Commands

```
rh-mod-skills ingest plan <model> --source FILE [--source FILE ...] [--origin-url URL]
rh-mod-skills ingest approve <model>
rh-mod-skills ingest implement <model> [--acknowledge-drift]
rh-mod-skills ingest verify <model>
```

Plan writes `models/<model>/process/plans/ingest-plan.yaml` (`status: draft`).
Implement copies originals to `sources/raw/`, checksums, writes
`sources/projections/*.yaml` when `projection: tables`. Event: `source_added`.
Verify is read-only.

## Source types

| Suffix | `type` | Default projection |
|--------|--------|--------------------|
| `.xlsx` / `.xlsm` | excel | tables |
| `.csv` | csv | tables (one sheet named from the file stem) |
| `.pdf` | pdf | tables if reconstructable; else skipped |

Other suffixes: still register; projection skipped. Markdown is never an acceptable
sole L1 projection.

## Ingest plan fields

| Field | Meaning |
|-------|---------|
| `path` | Path passed to `--source` (not yet copied) |
| `name` | Slug from the filename |
| `type` | excel / csv / pdf |
| `origin_url` | Public catalog URL when known |
| `projection` | `tables` or `skipped` |
| `skip_reason` | Why skipped (PDF) |
| `tables` | Detected PDF tables (004) |

### Skip reasons

| `skip_reason` | Meaning | Skill action |
|---------------|---------|--------------|
| `no-text-layer` | Image-only PDF | Register-only. No OCR. |
| `no-tables-detected` | Text but no reconstructable grid | Register-only. Do not invent rows from prose. |
| `no-tables-approved` | Reviewer excluded every table | Register-only. |
| `extractor-error` | pdfplumber failed | Report; do not hand-build a sheet. |

### PDF `tables[]`

| Field | Meaning |
|-------|---------|
| `id` | `t1`, `t2`, … |
| `name` | Caption (`Table 1`) or page fallback |
| `pages` | 1-based page list (continued tables span pages) |
| `columns` | Header cells |
| `row_count` | Data rows after header |
| `warnings` | e.g. `continued-header`, `continued-without-header` |
| `decision` | `include` or `exclude` (reviewer) |
| `reason` | Required when exclude |

Implement writes only `include` tables into the projection (same YAML shape as Excel).

## Projection shape (Excel/CSV/PDF)

```yaml
source: <filename>
type: excel   # csv | pdf
sheets:
  - name: Variabelen    # or Table 1
    columns: [variabele_name, variabele_categorie, variabele_label]
    rows:
      - [gebdat, Patiëntgegevens, Geboortedatum]
```

Do not edit this file by hand. Re-run ingest implement after an approved plan change.

## Drift

Verify reports checksum mismatch as blocking. Implement with L2 present and a
changed source fails unless the reviewer passed `--acknowledge-drift`. The skill
must not use that flag on its own.

## Out of scope here

Extract column roles (`rh-mod-extract`). Terminology (`rh-mod-annotate`).
Datatypes. Mapping workbooks.
